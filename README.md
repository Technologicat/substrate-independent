## Keeping up

The documents are edited in place — new entries appear at their alphabetical or thematic position, and existing ones get revised — so there is no single place where the newest material collects. The commit log is the changelog: subscribe to [the Atom feed](https://github.com/Technologicat/substrate-independent/commits/main.atom), or watch [the commit history](https://github.com/Technologicat/substrate-independent/commits/main).

Commit subjects name the entries touched and distinguish additions from revisions, so the feed alone usually says whether a change is worth reading.
